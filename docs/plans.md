# Возможные улучшения

* Читать сокращения jdm, jdn, etw полностью при генерации аудио
* Борьба с омонимами: например, если указана подсказка перевода, дать её генератору предложения, чтобы генерировал именно в этом значении
* Когда у слова несколько возможных переводов, добавлять уникальный префикс `(starts with <unique prefix>)` – сейчас делаю вручную. 
  Например, "мнение" – Meinung, Ansicht, Erachtens.
* Разделение генерации на несколько этапов в UI для верификации человеком
  * Например, сначала перевести слова, дать человеку проверить, и уже потом генерировать предложения.
  * Или дать возможность перегенерировать предложение, если оно херовое (например, частая ошибка – генерит для похожего слова другой части речи, например Schwimmen сущ → schwimmen глагол).
