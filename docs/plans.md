# Возможные улучшения

* Проблема: весь реквест фейлится из-за ошибки в одном слове.
  Либо делать один реквест на каждое слово, либо мочь отдавать часть ответа, если где-то произошли ошибки.
* Качество перевода googletrans оставляет желать лучшего
* Более лучшая обработка ситуации когда существительное не нашлось в словаре (сейчас NotImplementedError).
  Конкретные примеры: Selbsteinschätzung, Klimmzugstange, Berufseinstieg, Erachten, Achterbahnfahren, Freiklettern, Tiefseetauchen, Eisbaden, Fallschirmspringen.
* Есть какие-то слова, когда оно детектит неверную часть речи (особено аджективы), и в итоге искажает слово, и к тому же зачитывает неверный вариант. Например angetrunken, bewusst
* Читать сокращения jdm, jdn, etw полностью при генерации аудио
* Для немецких глаголов добавить информацию отделяемая приставка или нет
* Если указана подсказка перевода, дать её генератору предложения, чтобы генерировал именно в этом значении
* Когда у слова несколько возможных переводов, добавлять уникальный префикс `(starts with <unique prefix>)` – сейчас делаю вручную. 
  Например, "мнение" – Meinung, Ansicht, Erachtens.
